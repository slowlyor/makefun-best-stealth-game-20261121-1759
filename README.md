Mothlight is a top-down stealth heist: Pip the moth-thief sneaks past patrolling wardens, hides in bushes, tosses pebbles to lure guards away, and steals every moon shard before slipping out the exit unseen.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys, hold Shift to sneak, click to toss a pebble.
